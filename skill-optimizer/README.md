# Skill Optimizer

让技能更容易被发现、更准确被调用、更清晰被理解。

## 功能

- **命名优化**：检查并建议符合 kebab-case 的清晰命名
- **描述增强**：添加多语言触发关键词，提升搜索命中率
- **边界澄清**：定义 When to Use / Do NOT Use，减少误调用
- **交叉引用**：建立技能间的关联网络，提升连带使用率
- **README 集成**：确保技能在仓库首页可见且描述精准
- **技术 SEO**：标签、结构、示例的全面审计

## 适用场景

- 新技能发布前的最终检查
- 旧技能发现率低、使用率差的诊断与改进
- 技能命名冲突的解决
- 批量优化整个技能库的可发现性

## 使用方法

在对话中调用：
```
帮我优化 BP_Generator 这个 skill
```

或：
```
对我的 skills 做一轮 SEO 审计
```

## 输出示例

优化报告包含：
1. **总体评分** (0-100)
2. **7 维度审计**：命名、描述、边界、交叉引用、约束、README、技术 SEO
3. **优先级行动清单**：Critical → High → Medium → Low
4. **优化后的 SKILL.md**：可直接应用的完整版本
